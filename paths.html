Learning paths

Start from zero. Then choose a role.

Foundations assumes no security job, no networking background, and no programming experience. The six role paths come after that sequence.

00Absolute beginner8–12 weeks

ZeroTrace Foundations

Start here if computers, networks, Linux, or programming are new. The sequence below is the same order inside the Academy. Early topics can be skipped only after a placement check.

  1. 01Digital Literacy
  2. 02Computer Hardware and Software
  3. 03Operating System Fundamentals
  4. 04Windows Fundamentals
  5. 05Linux Fundamentals
  6. 06Networking Fundamentals
  7. 07Internet and Web Fundamentals
  8. 08Programming Fundamentals
  9. 09Mathematics and Logic
  10. 10Cybersecurity Introduction
  11. 11Basic Security Practices
  12. 12Security Tools Introduction
  13. 13Ethics and Legal Fundamentals
  14. 14Cybersecurity Terminology
  15. 15Beginner Practical Assessment

Continue in the Academy

01Beginner → Advanced6–9 months

Ethical Hacker

Learn to think like an attacker and test systems legally, methodically, and professionally.

  1. 01Foundations
  2. 02Networking
  3. 03Linux
  4. 04Reconnaissance
  5. 05Web Security
  6. 06Penetration Testing
  7. 07Reporting

Skills: recon methodology, web exploitation in authorised labs, privilege escalation, professional reporting.

02Beginner → Intermediate5–7 months

SOC Analyst

Build the defensive skills a security operations centre expects from day one.

  1. 01IT Fundamentals
  2. 02Networking
  3. 03Windows & Linux Logs
  4. 04SIEM
  5. 05Alert Triage
  6. 06Threat Hunting
  7. 07Incident Response

Skills: log analysis, SIEM querying, alert triage, escalation and reporting.

03Intermediate6–8 months

Digital Forensics Investigator

Preserve and analyse digital evidence so your findings hold up to scrutiny.

  1. 01Foundations
  2. 02Evidence Preservation
  3. 03Disk Forensics
  4. 04Memory Forensics
  5. 05Network Forensics
  6. 06Case Reporting

Skills: chain of custody, timeline analysis, memory analysis, case documentation.

04Intermediate → Advanced6–9 months

Cloud Security Engineer

Design, secure, and monitor cloud workloads across identity, network, and data.

  1. 01Cloud Fundamentals
  2. 02IAM
  3. 03Network Security
  4. 04Storage Security
  5. 05Logging & Monitoring
  6. 06Container Security
  7. 07Cloud Incident Response

Skills: least-privilege IAM, cloud logging, posture review, cloud incident response.

05Advanced8–12 months

Malware Analyst

Take malicious code apart safely and turn findings into detections.

  1. 01Programming
  2. 02Operating Systems
  3. 03Binary Fundamentals
  4. 04Static Analysis
  5. 05Dynamic Analysis
  6. 06Reverse Engineering

Skills: assembly reading, sandbox analysis, indicator extraction, detection rules.

06Intermediate → Advanced8–12 months

Security Engineer

Build secure systems and pipelines instead of only finding what is broken.

  1. 01Programming
  2. 02Networking
  3. 03Linux
  4. 04Secure Development
  5. 05DevSecOps
  6. 06Cloud Security
  7. 07Security Architecture

Skills: secure code review, CI/CD security, threat modelling, architecture design.
